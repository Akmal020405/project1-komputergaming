## 📂 Struktur Proyek Utama

Proyek ini mengikuti struktur standar Unity:

* `Assets/`: Berisi semua aset game.
    * `Materials/`: Bahan dan tekstur yang digunakan untuk objek.
    * `Scenes/`: File scene game (termasuk `SampleScene`).
    * `Scripts/`: Semua script C# untuk logika game, kontrol pemain, dll.
